# Day 04 — User Input and Interactive Programs

**Language:** Python  
**Topic:** User Input and Interactive Programs  
**Status:** Review pending

## Learning Objectives

- Understand how Python collects user input.
- Use the `input()` function.
- Store user responses in variables.
- Understand why `input()` returns a string.
- Convert user input using `int()` and `float()`.
- Perform calculations using user-provided values.
- Combine strings through concatenation.
- Format text using `.strip()` and `.lower()`.
- Develop basic interactive programs.

## Practical Applications

User input allows programs to interact with people instead of relying only on predetermined information.

These concepts are useful for building command-line applications, calculators, registration systems, inventory tools, and interactive automation scripts.

They also provide a foundation for future cybersecurity tools that accept user-defined settings and commands.
