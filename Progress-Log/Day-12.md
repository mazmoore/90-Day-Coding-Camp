# Day 12 — String Methods and Text Manipulation

**Language:** Python  
**Topic:** String Methods and Text Manipulation  
**Status:** Review pending

## Learning Objectives

- Understand the purpose of string methods.
- Use `upper()` and `lower()` to change letter capitalization.
- Use `capitalize()`, `title()`, and `swapcase()`.
- Remove unwanted whitespace using `strip()`, `lstrip()`, and `rstrip()`.
- Replace text using `replace()`.
- Count occurrences using `count()`.
- Search for text using `find()`, `rfind()`, and `index()`.
- Check prefixes and suffixes using `startswith()` and `endswith()`.
- Split strings into lists using `split()`.
- Combine strings using `join()`.
- Check text contents using `isalpha()`, `isdigit()`, and `isalnum()`.
- Format text using alignment and padding methods.
- Normalize user input.
- Chain string methods together.
- Understand string immutability.
- Apply string methods to cybersecurity log processing.

## Practical Applications

String methods help clean, organize, and process text-based information.

They are useful for user input handling, business data management, filename processing, reporting, and application development.

In cybersecurity, string methods support security log analysis, event classification, username normalization, and structured text processing.
